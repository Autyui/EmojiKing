# EmojiKing

EmojiKing 是一款面向 Android 的本地表情图库和中文输入法。它让用户在手机本地整理表情包，并在聊天应用中快速发送图片或输入中文。

## 当前功能

- 从相册、文件选择器或授权目录导入 PNG、JPEG、WebP、GIF 等图片。
- 创建多个图库和表情包，同一表情包可以加入多个图库。
- 重命名、删除图库和表情包；在单个类中多选删除表情。
- 为表情添加备注，查看图片详情并支持放大、缩小。
- 删除只影响应用内记录和托管副本，不会删除手机相册中的源文件。
- 中文拼音输入、英文直输和表情图库切换。
- 顶部候选栏最多显示 15 个候选，展开后可查看当前拼音的全部候选。
- 支持标准图片提交；目标应用不支持时自动降级为图片分享。
- 支持从系统相册选择键盘背景，图片保存在应用私有目录。

## 后续更新

1. 增加更多联想词、短语和上下文候选，继续优化候选排序和响应速度。
2. 增加更多输入法模式，例如九宫格、双拼、数字符号和更多键盘布局。
3. 优化表情包使用体验，加入最近使用、收藏、搜索、排序和更快捷的发送流程。
4. 完善图库与表情包的批量管理、跨图库选择和备注数据联动。
5. 保留 GitHub 图床和云端同步接口，后续再实现正式服务、鉴权和数据同步；本地功能不依赖云端。
6. 持续扩大主流聊天应用、Android 版本和横竖屏场景的兼容性验证。

## 隐私与数据

图片默认保存在应用私有目录。导入、整理、删除和发送均不会主动删除手机相册源文件。云端功能为可选接口，正式版本不内置个人账号、密钥或 GitHub 凭据。

## 构建

项目使用 Android Gradle Plugin 7.3.1 和 JDK 11：

```powershell
$env:JAVA_HOME = 'E:\Tools\android\jre'
.\gradlew.bat :app:assembleDebug
```

正式构建：

```powershell
.\gradlew.bat :app:assembleRelease
```
