# 本地表情输入法兼容性原型

这是一个 Java 编写的最小 Android 原型，验证三件事：

1. 从系统文件选择器导入一张本地图片。
2. 目标输入框声明支持图片时，通过 `commitContent` 标准接口提交。
3. 目标未声明支持或拒绝标准提交时，向当前应用发起图片分享。

应用内的测试输入框声明支持 `image/*` 并实现了接收端，可先验证输入法、URI
授权和图片读取的完整本地链路。普通 `EditText` 默认不会声明富媒体类型。

## 构建

项目使用 Android Gradle Plugin 7.3.1，需要 JDK 11：

```powershell
$env:JAVA_HOME = 'E:\Tools\android\jre'
.\gradlew.bat :app:assembleDebug
```

APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 发送策略

点击输入法中的图片后：

- 当前输入框声明支持图片 MIME 时，先调用标准 `commitContent`。返回 `true` 后立即结束，不再打开分享。
- MIME 不匹配、声明为空或标准提交返回 `false` 时，优先打开当前输入框所属应用的图片分享入口。
- 当前应用不能处理图片分享时，打开系统分享选择器。
- “分享发送”按钮始终手动打开分享，用于目标接受标准提交但没有显示图片的情况。

“标准提交已接受”仅表示目标输入连接接受了调用；“已打开目标应用分享”和“已打开系统分享选择器”仅表示对应界面已启动。这些提示都不代表图片已经发送成功。

## 实机验证

1. 安装并打开 APK。
2. 点击“导入一张本地图片”，选择 PNG、JPEG、WebP 或 GIF；也可直接使用默认示例图。
3. 点击“打开系统输入法设置”，启用“本地表情输入法”。
4. 先点击应用内的“本地接收测试”输入框，切换输入法并点击图片；应看到“本地链路通过”和接收预览。
5. 在微信输入框中点击图片；若微信声明支持当前 MIME，应直接提交且不打开分享界面。
6. 打开 QQ 私聊输入框并切换到“本地表情输入法”。
7. 点击图片；当前实测 QQ 未声明富媒体 MIME，应直接打开 QQ 分享确认界面并显示图片预览。
8. 点击“分享发送”，确认可以手动再次打开当前应用分享。

结果判定：

- 微信标准提交被接受后不应同时出现分享界面，避免重复发送。
- QQ 分享界面可能要求重新选择会话或确认发送，这是系统分享的预期边界。
- 目标应用没有图片分享入口时，应出现系统分享选择器或明确的失败提示，不应崩溃。

主界面的“通过系统分享测试图片”是对照入口，可独立检查图片 URI、权限和文件本身是否正常。
